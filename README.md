# E-Commerce Fumetteria

Progetto full-stack con architettura divisa tra Frontend e Backend.

## 🛠️ Stack Tecnologico Utilizzato

- **Frontend:** React, Vite, Tailwind CSS (Architettura Atomica).
- **Backend:** Node.js, Express, JavaScript (ES Modules).
- **Database:** PostgreSQL gestito in ambiente isolato tramite **Docker**.
- **ORM & Configurazione:** Prisma v7 con supporto TypeScript (`prisma.config.ts`).
